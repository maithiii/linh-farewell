# Linh's Next Adventure — Farewell Card

A responsive single-page farewell card built with HTML, CSS, and JavaScript.

## Run locally
1. Extract the `linh-farewell` folder.
2. Open `index.html` in a modern browser.
3. Keep the `assets` folder next to `index.html`; the photos and videos use relative paths.

## Included media
- `assets/photos/memory-01.jpg` through `memory-12.jpg`: the photos supplied for Linh's card.
- `assets/videos/moment-01.mp4` through `moment-06.mp4`: the supplied videos, with manual playback controls. The longest newly added clip is featured last as the company-trip finale.
- `assets/team-song.mp3`: optional background music file. Add a song you have permission to use with this exact filename to enable the music toggle.

## Customize
Edit the captions and messages in `index.html`. The current farewell messages are generic placeholders; replace them with real notes from the team before sharing.

## Deploy
Upload the entire folder to a static host such as Netlify or Vercel. Do not upload only `index.html`, because the media files are stored in `assets/`.
